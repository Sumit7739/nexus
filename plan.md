1. Desktop "Spaces" (1-Click Context Switching)

A lightweight workspace switcher in the Dock (or Alt + 1 / 2 / 3) for modes like Deep Work, Research, and Unwind.

    Each Space remembers its own window layout/split-tiling, visible desktop widgets, wallpaper, and linked Music stream or playlist.

    Switching to Deep Work can automatically tile Scratchpad + Browser, swap to a calm dark wallpaper, and start your focus playlist in one click.

2. Procedural Soundscape Mixer (Layered Over Music)

A zero-dependency Web Audio atmosphere engine built into Music (and controllable via window.NEXUS.music).

    Layer soft rain, vinyl crackle, fireplace, brown noise, or night crickets underneath whatever YouTube track or focus radio is currently playing, each with its own individual volume fader.

    Save custom mixes (e.g., Jazz Piano + Rain + Vinyl) as presets.

3. Focus Sessions Tied to Scratchpad Tasks

Promote focus from a standalone timer into a cross-app desktop ritual:

    Pick any - [ ] task from Scratchpad, start a 25m or 50m session, and watch a quiet countdown appear in the Dock/top edge.

    Automatically starts (and fades out at break time) your chosen Music stream, optionally hides non-essential windows, and lets you check off the Scratchpad task with logged focus minutes when the chime sounds.

4. "Stash" Edge Shelf (Universal Drop Zone & Snippet Tray)

Inspired by Yoink / Raycast — a sleek slide-out shelf on the screen edge for temporary things that don't deserve a full note yet:

    Drop or send text snippets, code blocks, hex colors, quick calculations, URLs, or YouTube links from Browser, Scratchpad, or Spotlight.

    One click converts any stashed card into a Scratchpad note, a Saved Link, a Music queue item, or copies it back to your clipboard.

5. AI Widget Crafter + NEXUS.notes Bridge in Widget Studio

Take Widget Studio two steps further:

    NEXUS.notes & NEXUS.shortcuts APIs: Let custom widgets read and check off real - [ ] tasks from your Scratchpad notes or launch your Saved Links dynamically.

    Prompt-to-Widget in Workbench: Since Gemini is already wired on your server, describe a widget in plain English (e.g., "A retro cassette player for NEXUS.music" or "A habit streak grid using NEXUS.setLocal") to generate editable HTML/CSS/JS/JSON directly into the live preview.

6. "Dayline" — Daily Time-Blocker & Auto-Journal

A calm daily planner built for a New Tab page:

    Automatically links a daily Scratchpad note (Oct 30) with a visual hour-by-hour timeline where you can drag - [ ] tasks from Scratchpad into time blocks, plus multi-timezone clocks for teammates and local weather — all 100% local and included in Workspace JSON backup.

7. Developer Swiss-Army App ("DevBox" + Spotlight Inline Tools)

If you live in the browser while building software:

    Instant Spotlight inline conversions (#ff6b4a to hsl, unix 1761820000, base64 ..., uuid) alongside a clean DevBox window for JSON formatting/diffing, JWT inspection, Regex testing, Cron humanizer, and contrast checking — with one-click export to Scratchpad.
